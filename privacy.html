Privacy policy

rclone-pool is used only by its owner, on the owner's own computers.

  • It requests the drive.file scope, so it can only access files it created itself.
  • Access tokens are stored locally on the owner's machines and are never shared with anyone.
  • No data is collected, sold, or transferred to third parties.

Google user data is used solely to store and retrieve the owner's own files, in line with the Google API Services User Data Policy.
